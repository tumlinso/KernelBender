# Decisions already supported by the sources

| Finding | Consequence |
|---|---|
| The CUDA machine-aligned guide already asks for semantic units, unlike representations and lifetime costs. | Use it in the comparison baseline; do not market KernelBender as inventing representation-first design. |
| Atlas C39 is a proposed method, not a demonstrated optimal prompting strategy. | Retain its useful structure but remove mandatory candidate quotas. |
| Atlas E39's slight bitplane median advantage is inside an interval crossing zero. | No established representation crossover is imported. |
| E09 verifies a selected explicit PTX form, not raw WMMA ownership. | The mechanism bridge keeps this boundary and a map check. |
| KDA's direct merge record holds the partial kernel fixed but changes the merge as a bundle. | Teach a combined causal intervention; do not isolate individual levers without extra evidence. |
| The KDA study found a race in a historical materialized baseline. | Use corrected baseline source and fresh performance identities in any new pilot. |
| The low-bit comparison changes arithmetic engine and decode placement together. | Do not infer an intrinsic disadvantage of consumer-native decoding. |
| The recurrence study mixes launch reduction and retained ownership. | It is not a direct measurement of HBM bytes saved. |
| ncu's broad “profile before plan” wording assumes an existing implementation. | Greenfield hypotheses need not wait for nonexistent profiles; measured diagnosis remains evidence-led. |
| Public intrinsic availability can include software lowering. | Distinguish compilability, native target support and an observed generated path. |
| KDA register requires source/manifest; attachment kinds are profile/sass/ablation. | Use existing docs/hypothesis text for design output, not invented engine fields or statuses. |
| Native Todo persists `notes`, `produced_artifacts`, dependencies and gates explicitly. | Put acceptance/input references in native notes/artifacts rather than relying on arbitrary ignored task fields. |
| `src/todo_orchestrator/plan.py` is readable; stale search results pointed to nonexistent alternate paths. | Use verified native paths and inspect actual CLI grammar, not a guessed new layout. |
| Plan validation is available only on the user's installed authority, not this read-only connector. | Package checks are structural; live native validation/application remains intake work. |
| Several external full-text URLs failed, while abstracts were available. | Scope the research claim to the material actually inspected; do not claim a comprehensive paper audit. |

No CUDA/Atlas replacement, KDA runtime change or cross-workspace implementation was performed during this design. The sources contain more possible work than this task needs; whole driver/firmware, multi-GPU runtime and generalized optimizer projects are not hidden tasks in the bootstrap.
